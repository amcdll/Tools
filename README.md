## 1. Num to Text
### 简介
这是一个可以将数字转换为对应自然语言的程序。暂时只有转中文的，并且只支持整数。
### 运行
需要一个Python3解释器
### 如何使用
启动程序时输入一个不超过10位的数字，但是不能输入出现以下几种情况：
(1) abc、123abc、@#$%等等不是数字的组合
(2) 01、010等等开头是0的组合
(3) 数字超过10位
(4) +0和-0
